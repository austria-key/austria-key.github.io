# Австрия Ключ: публичные документы

Статичные политика конфиденциальности, условия использования и помощь пользователю.
Оператор: ТСН «Астрия». Контакт: info@kk-austria.info.

GitHub Pages публикует ветку `main`, корневой каталог `/`.
Исходный код приложений, доступы, реестр и ключи в этом репозитории отсутствуют.

В `review/` находятся только публичные демонстрационные QR/JSON для проверки импорта.
Они используют калитку `austria-review-demo`, не зарегистрированы в реестре и не дают доступа к настоящему оборудованию.
