Австрия Ключ для Android

Версия 1.0.0 (3). Отдельный установочный APK для Android 8.0 и новее. Для работы необходимы Bluetooth LE и поддержка системного Companion Device Manager.

Скачать APK — 378 КБ

Этот APK не требует Google Play, аккаунта Google или Google Services. В него не встроена дополнительная проверка источника установки Google Play. Верификация ключа и Bluetooth-команд калитки сохранена. Само приложение не использует интернет; контроллер калитки обновляет доступ через собственный Wi-Fi.

Установка

  1. Загрузите APK на телефон по ссылке выше. Для загрузки нужен интернет браузеру, а не приложению «Австрия Ключ».
  2. Откройте скачанный файл. Если Android попросит разрешить установку из этого источника, разрешите её выбранному браузеру или файловому менеджеру для этой установки.
  3. Подтвердите установку системным диалогом Android. После установки можно снова запретить установку из данного источника.
  4. Откройте приложение и добавьте рабочий QR-код или файл доступа, выданный администратором. Загрузка приложения сама по себе не даёт права открыть калитку.

Если приложение уже установлено

Пакет APK — ru.austria.key. Эта сборка подписана отдельным постоянным сертификатом загрузки проекта. Сертификат версии из Google Play или прежней debug-сборки может отличаться: тогда Android не разрешит обновление поверх неё. Изменение источника установки не переносит доступ автоматически.

Не удаляйте рабочее приложение и его данные только ради установки APK. Удаление может уничтожить ключ телефона; ранее активированный QR не привяжется повторно к новому ключу. Сначала согласуйте с администратором новый доступ или дальнейшее использование уже установленной версии. Повторная установка APK с тем же сертификатом и допустимым номером версии обычно сохраняет данные, но переход с другой подписи не является таким обновлением.
