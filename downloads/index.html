Австрия Ключ для Android

Версия 1.0.0 (3) для Android 8.0 и новее. Для открытия калитки нужен Bluetooth.

Скачать APK — 378 КБ

Этот способ установки подходит для телефонов без Google Play. Для использования приложения Google-аккаунт не требуется. Приложение работает без интернета.

Установка

  1. Загрузите APK на телефон по ссылке выше. Для загрузки нужен интернет браузеру.
  2. Откройте скачанный файл. Если Android попросит разрешить установку из этого источника, разрешите её выбранному браузеру или файловому менеджеру для этой установки.
  3. Подтвердите установку системным диалогом Android. После установки можно снова запретить установку из данного источника.
  4. Откройте приложение и добавьте рабочий QR-код или файл доступа, выданный администратором. Загрузка приложения сама по себе не даёт права открыть калитку.

Если приложение уже установлено

Android может не разрешить установить эту версию поверх приложения из другого источника, например Google Play.

Не удаляйте рабочее приложение или его данные ради установки APK. Это может удалить сохранённый ключ. Старый активированный QR не восстановит доступ после удаления ключа. Если обновление не устанавливается, сначала обратитесь к администратору.

QR для загрузки

Отсканируйте обычной камерой, чтобы загрузить файл. Это QR установки, не ключ доступа к калитке.
